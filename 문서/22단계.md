# 22단계 — 7B 전체: 머리 128 의 어텐션까지 글(geul) 언어로 (2026-10-11)

21단계는 7B(Qwen2.5-7B-Instruct Q8_0)의 행렬곱만 쟀다. 결과는 프롬프트 2048 에서 r 1.20, 8192 에서 r 1.77 이었다. 이 단계는 7B 를 통째로
돌린다. 사용자 결정(2026-10-11): "행렬곱 먼저, 그다음 전체" — 그 "전체"가 이 단계다.

7B 의 머리 크기는 128 이다(0.5B 는 64). 그래서 어텐션의 계약과 커널을 넓혀야 한다. 판정 기준을 결과보다 먼저 적는다.

## 계약을 넓힌다 — 머리 크기 128 (문서/계약.md 에 더한다)

0.5B(머리 64)의 계약은 바뀌지 않는다. 머리 128 에서 다른 것은 셋이다.

1. **점수의 눈금.**
   - 머리 64 는 × 0.125 로, 2 의 거듭제곱이라 정확하다.
   - 머리 128 의 1/√128 은 2 의 거듭제곱이 아니다. 그래서 상수 c = 짧은실수(1/√128) = 0.088388346…(가까운 반올림)을 정하고 s ← s × c 를
     **곱 한 번(반올림 하나)**으로 적는다.
   - 그 앞의 점수 합은 32 칸 블록 넷을 b 오름차순으로 곱해더하기 사슬로 잇는다(블록 0 이 처음 값 — 머리 64 의 둘과 같은 꼴).
2. **RoPE.** 표 cos · sin 은 [위치][64] 다. θ_i = θ^(−2i/128)(i = 0 … 63)을 fp64 로 바르게 하고, 각 = 위치 · θ_i(fp64 곱), cos · sin 은
   짧은실수로 바르게 반올림한다. 돌리는 짝은 (i, i + 64)이다. 곱해더하기의 꼴은 머리 64 와 같다.
3. **출력 o_d** 는 값의 32 칸 블록 넷(d 0 … 127)마다 머리 64 와 같은 식이다. 적힌지수 · 합 l · 접기(두 층)는 그대로다.

## 무엇을 만드나

- **CPU 참조**(`계약/정수계약.py`)를 머리 크기에 따라 넓힌다(머리 64 의 값은 그대로).
  - 7B 의 앞으로(정수 계약)는 시간이 들기 때문에, 정수 블록의 합을 짧은실수 BLAS 로 셈한다. 블록 하나의 합이 2¹⁹ 아래라 순서와 상관없이
    정확하다.
  - 이 빠른 판이 `정수계약.행렬곱` 과 비트까지 같은지는 따로 시험한다.
- **커널 생성기**(글 — `커널/생성*.gl`)에 모델의 크기를 매개변수로 넣는다.
  - 7B 모듈 `qwen2Q8_7b.gl` 을 낸다. 0.5B 모듈은 바이트까지 그대로 둔다(19a 를 다시 본다).
  - 7B 모듈의 커널:
    - 정수 타일 판(끝손질 없음 · 잔차 · SwiGLU — K · N 은 띄울 때 받는다)
    - 줄 판(행 넷까지)
    - RMS 정규화
    - 임베딩
    - RoPE + KV(머리 128)
    - 프롬프트 어텐션(묶음 판 + 묶음 접기 — 머리 128, 새로)
    - 생성 어텐션(조각 + 조각 접기 — 머리 128)
    - SwiGLU 줄
    - 로짓 · 가장 큰 번호
- **호스트**(글)를 7B 크기로 넓힌다.
  - 프롬프트는 1024 행 이하의 덩이로 넣는다. 계약상 비트가 같다(20a). 21단계의 L2 틈도 이것으로 피한다.
  - 생성은 토큰마다 CUDA 그래프로 돌린다(7B 에는 생성 메가커널을 아직 만들지 않는다).
  - 실행기가 7B GGUF 를 받는다.

### 미리 밝혀 둘 것

1. **계약을 넓힌다(위).** 머리 128 의 점수 눈금은 반올림 하나를 더한다. 머리 64 는 그대로다.
2. **QKV 는 끝손질 없는 타일 판에 RoPE + KV 커널을 따로 잇는다.** 0.5B 의 QKV 타일 끝손질(RoPE · KV 를 타일 안에서)은 머리 64 에 묶여 있다.
   따로 잇는 길은 활성값을 한 번 더 쓰고 읽는다.
3. **프롬프트는 1024 행 이하의 덩이로 넣는다.** 어텐션은 묶음 판 하나만 쓰고, 행렬곱은 L2 에 드는 크기로 간다.
4. **생성은 토큰마다 그래프다.** 0.5B 의 생성 메가커널(15단계)은 크기에 맞춰 짜여 있어 7B 에는 아직 없다.
5. **머리 128 의 어텐션 커널은 새로 짠 첫 판이다.** 0.5B 커널처럼 바닥까지 다듬지 않았다. 속도는 그대로 적는다.
6. **최대 문맥은 8192 다.** 12 GB 에 7B Q8_0(8.1 GB)과 정수 KV 캐시를 둔다.
7. **대조 도구는 파이썬이다**(CPU 참조 · 견주기). 엔진과 실행기는 글이다.
