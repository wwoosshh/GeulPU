# 19단계 — 커널 생성기를 글로: 빌드까지 글 컴파일러와 CUDA 드라이버만으로 (2026-10-11)

사용자 결정(18단계): "다른 언어의 종속없이 글컴파일러와 cuda dll만 통해서 작동하도록 구성해야해". 18단계 뒤 사용자의 물음(2026-10-11):
"이제 완전히 글, cuda 두가지로 진행가능해진거야?" — 답: 실행은 그렇다(실행기 = 글 실행 파일 + nvcuda.dll). 빌드는 아니다 — 실행기가 읽는 PTX 의
글 소스(`qwen2Q8.gl`, 6.8 MB)를 파이썬 생성기 `커널/커널생성.py` 가 만든다(그다음 PTX 로 옮기는 것은 글 PTX 뒷단 `자체PTX.exe`).

이 단계는 생성기를 글로 옮겨, 새로 받은 저장소에서도 **글 컴파일러가 빌드한 생성기 → 글 소스 → 글 PTX 뒷단 → PTX → 글 실행기 + nvcuda.dll**
로 파이썬 없이 채팅까지 가게 한다. 판정 기준을 결과보다 먼저 적는다.

## 할 것

- **글 생성기**(`커널/` 의 글 파일들) — `커널생성.qwen2_source()` 와 같은 소스를 낸다. 자체 호스팅 컴파일러(geul-lang-v2 `build/self_컴파일러.exe`)로
  빌드한다. 쓰는 법: `커널생성 qwen2Q8 <출력.gl>`.
- 옮기는 것은 `qwen2_source()` 가 지나는 길 — `sys.settrace` 로 세면 파이썬 2,395 줄 · 함수 72 개(생성기 6,781 줄 가운데): 정수로 · RMS 정규화 ·
  정수 타일 판 모두(끝손질 셋 · 열먼저 · 로짓) · 정수 줄 판 · 임베딩 · RoPE+KV · SwiGLU · 가장 큰 번호 · 정수 KV 어텐션(프롬프트 · 갈래 · 묶음 ·
  두 층 · 생성 조각 · 접기) · 칸 판 · 묶은 줄 판 · 생성 메가커널.
- 빌드는 명령 둘: `커널생성 qwen2Q8 qwen2Q8.gl` → `자체PTX qwen2Q8.gl -o qwen2Q8.ptx`.

## 판정 (미리 정함)

| 판정 | 기준 (미리 정함) | 상태 |
|---|---|---|
| 19a 바이트 | 글 생성기가 낸 `qwen2Q8.gl` 이 파이썬 생성기(`커널생성.qwen2_source()`)의 출력과 바이트까지 같다 — 6,779,678 B, SHA-256 `0f3153c8…` | |
| 19b 의존 | PATH 를 Windows 시스템 폴더만으로 둔 환경(파이썬이 없다)에서 처음부터: 자체 호스팅 컴파일러가 생성기 · 실행기를 빌드 → 생성기가 `qwen2Q8.gl` → `자체PTX.exe` 가 PTX(지금 실행기가 쓰는 것과 바이트까지 같아야 — 52,494,659 B, SHA-256 `d85f7ec7…`) → 실행기가 시험 질문 셋의 채팅을 18a 와 같은 답으로. 생성기 실행 파일의 가져오기 표는 `kernel32.dll` · `shell32.dll`(글 런타임) 뿐 | |
| 19c 시간 | 생성기 한 번(프로세스 시작에서 출력 파일을 다 쓸 때까지)이 파이썬 생성기(인터프리터 시작 · `import 커널생성` · `qwen2_source()` · 파일 쓰기)보다 오래 걸리지 않는다 — 프로세스를 번갈아 다섯 번씩, 중앙값 | |

판정이 아닌 기록: 글 생성기의 줄 수, 들인 시간, 빌드 시간(생성 · PTX).

### 미리 밝혀 둘 것

1. **범위는 Qwen2 모듈**(`qwen2Q8.gl` — 실행기가 쓰는 것). GPT-2 의 모듈 22 개는 파이썬 생성기 그대로 둔다 — 그것을 쓰는 것은 파이썬 연구
   엔진(`엔진/글gpt2.py`, 3 ~ 13단계의 기록)뿐이고 그 엔진은 파이썬이다.
2. **옮기는 것은 Qwen2 설정이 지나는 갈래만.** 다른 설정(짧은실수 · 반실수 KV, F16 · Q4_0, 가닥 계약, 자리 넷)의 갈래는 옮기지 않는다 — 글
   생성기는 Qwen2 설정 밖이면 다른 소스를 내지 않고 멈춘다(거부).
3. **정답지는 파이썬 생성기의 출력이다**(바이트 대조). 견주는 도구는 파이썬이어도 된다 — 빌드와 실행에는 들지 않는다.
4. **파이썬 엔진의 빌드 묶음**(`엔진/커널모듈.py` — 소스 · PTX 캐시)은 파이썬 엔진 쪽에 그대로 둔다. 글 쪽 빌드는 위의 명령 둘이다.
