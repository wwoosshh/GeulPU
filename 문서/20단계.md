# 20단계 — 품질: 퍼플렉시티로 본 숨은 손실 (2026-10-11)

제3자 평가(2026-10-10, 「글·GeulPU 연구 제3자 평가」)는 "숨은 손실 1/615"의 숫자는 맞지만 체감 의미는 과장되기 쉽다고 했다. 퍼플렉시티나
벤치마크로 품질 차이를 보인 적이 없고, llama.cpp 의 추가 KL(1.38 × 10⁻³)은 "Q8_0 가중치 양자화 자체의 손실과 같은 급"이라는 것이다.
그리고 다음 일로 품질 지표(퍼플렉시티)를 더하라고 했다. 사용자 결정(2026-10-11): "측정 진행해봐" — 퍼플렉시티(이 단계)와 7B 모델(21단계).
판정 기준을 결과보다 먼저 적는다.

## 무엇을 재나

- **모델**: Qwen2.5-0.5B-Instruct 공식 GGUF 둘 — Q8_0(14~19단계의 것)과 F16(같은 배포 — 형식 손실의 잣대). F16 은 사용자 허락으로
  내려받았다(1,266,425,696 B, SHA-256 8e0ae260…).
- **글**: wikitext-2-raw-v1 의 시험 글 `wiki.test.raw`(1,290,590 B, SHA-256 173c87a5…). llama.cpp 가 퍼플렉시티에 쓰는 바로 그 파일이다
  (ggml-org/ci 의 zip, 4,721,645 B, ef7edb56… — 사용자 허락으로 내려받았다). 둘 다 저장소에는 넣지 않는다.
- **방법**: llama.cpp b11496 의 `llama-perplexity` 와 같다.
  - 글 전체를 토큰으로 바꾼다(Qwen2 는 BOS 를 붙이지 않는다).
  - 512 토큰 덩이로 자른다(남는 꼬리는 버린다).
  - 덩이마다 위치 0 부터 따로 계산하고, 뒤쪽 절반을 채점한다: 위치 256 … 510 의 로짓이 다음 토큰(257 … 511)을 맞히는 음의 로그 확률(NLL)
    255 개.
  - PPL = exp(평균 NLL).
- **엔진 셋** — 같은 Q8_0 가중치:
  - **글**: 글(geul) 언어 도구 `호스트/퍼플렉시티.gl`. 글 엔진이 글 PTX 뒷단의 PTX 로 로짓을 내고, NLL 은 fp64 로 센다.
  - **llama.cpp** b11496: 공식 도구 `llama-perplexity` 의 기본 설정에 `-c 512` 를 준다(기본 n_batch 2048 이라 덩이 넷을 한 배치로 넣는다).
    KL 을 재려고 같은 계산을 C API 로도 돌려 로짓을 꺼낸다.
  - **참값**: GGUF 의 가중치를 풀어 fp64 로 계산한다(torch, GPU). Q8_0 은 q · d 로 정확히 풀린다. F16 가중치의 참값도 낸다.
- **지표**: PPL, 평균 KL(참값 ‖ 엔진)(채점한 토큰마다 어휘 전체의 분포로), 가장 큰 확률의 토큰이 참값과 같은 비율.

### 대조 (판정이 아니라 측정이 맞는지 — 맞지 않으면 고치고 밝힌다)

- **토큰**: 글 토크나이저, 파이썬 토크나이저, llama.cpp(C API)의 토큰이 같다.
- **방법**: C API 로 계산한 llama.cpp 의 덩이마다 누적 PPL 이 `llama-perplexity` 가 찍은 값(소수 넷째 자리)과 모두 같다.
  다르면 맞을 때까지 방법(배치 · 로짓 행)을 고치고 밝힌다.
- **같은 체크포인트**: Q8_0 의 값이 F16 가중치를 Q8_0 으로 양자화한 값과 맞는다. 블록마다 |q · d − w| ≤ d / 2 를 본다(F16 의 반올림
  만큼의 여유는 둔다). 맞지 않으면 20c 를 해석하지 않는다.
- **글 도구의 산수**: 글 도구의 PPL 이, 파이썬 대조 도구가 같은 로짓으로 계산한 PPL 과 상대 10⁻¹² 안이다. 같은 로짓은 파이썬 호스트가 낸다
  (같은 PTX — 18d 에서 비트가 같다).

판정이 아닌 기록: 토큰 수 · 덩이 수, PPL 의 표준 오차, 시간(글 도구, `llama-perplexity`), `llama-perplexity` 의 PPL 이 배치 설정(-b · -ub)에
따라 어떻게 바뀌는지.

### 미리 밝혀 둘 것

1. **글 엔진에 로짓 길 하나를 더한다.** 마지막 k 행의 로짓을 타일 판으로 낸다. 파이썬 호스트(`글qwen2.py` 의 로짓 = 정수)와 같은 커널 · 같은
   매개변수이고, 커널 모듈(`qwen2Q8.gl`)은 바뀌지 않는다. 판 고르기에 로짓 행렬곱을 더한다(어느 판이든 비트가 같다 — 계약).
2. **대조 도구는 파이썬이다.** 참값, KL, llama.cpp 로짓을 다루는 도구는 측정에는 들지만 글 엔진의 빌드 · 실행에는 들지 않는다. 글의 KL 은 파이썬
   호스트로 낸다(같은 PTX — 18d 에서 비트가 같다). 글 도구 자신은 PPL 을 낸다.
3. **범위는 하나씩이다.** 모델 하나(0.5B), 글 하나(wikitext-2), 문맥 하나(512). 일곱 배 큰 모델은 21단계에서 잰다.
4. **지표는 KL 과 PPL 이다.** MMLU 같은 과제 점수는 재지 않는다.
