# 35단계 — AMD 의 속도: 공유32 판의 어텐션과 행 여덟의 행렬곱

## 판정 기준 (재기 전에 적음 — 2026-10-15)

### 왜
- 34n 에서 AMD Radeon RX 9060 XT(RDNA4)가 NVIDIA 의 CUDA 기준과 비트까지 같았다. 속도는 못 미쳤다: R1 생성(슬롯 8)이 RTX 4070 Ti 의
  Vulkan 의 3.3 · 3.7 배다. 메모리 대역의 비(315 대 490 GB/s)는 약 1.6 배다.
- 친구 PC 의 자기 진단(협력 모듈 16x16x16 · 공유32 판): 한 줄 생성은 바닥의 1.27 배인데, 여덟 줄(문맥 2048)은 5.45 배(130 ms 중 어텐션
  57.8 ms, qkv · o · down 3.5 ~ 4.1 배), 프롬프트 2048 은 4.0 초 중 어텐션이 2.4 초다.
- 이 PC 에서 AMD 의 한도를 흉내 내도(공유 32 KB · 푸시 128 · 할당 2 GiB) 같은 꼴이다. 여덟 줄이 25.1 → 66.0 ms(어텐션 5.1 → 25.5,
  down 5.6 → 17.8), 프롬프트 512 의 어텐션이 6.4 → 22.4 ms.
- 원인 둘:
  - 공유32 판의 어텐션은 키 · 값을 한꺼번에 판에 올리느라(32 KB) 협력 행렬의 칸(질의 · D 판)을 둘 데가 없어 텐서곱을 흉내 낸다.
  - 줄 타일 판(32단계 — 행 여덟까지)이 40 ~ 49 KB 라 후보에서 빠진다.

### 고치는 것
- **공유32 의 협력 어텐션**: 키를 판에 올려 점수를 내고, 같은 자리에 값을 올려 가중합을 낸다(키와 값이 같은 때 판에 있지 않다).
  남는 자리에 워프마다의 질의 · D 판(협력 행렬), 생성 넷 판의 워프끼리 칸 · 지수 칸을 둔다(합 31.5 KB). 지수는 34m 처럼 전역에서 읽는다.
  셈의 식 · 차례는 그대로다.
  - 판 사이에 블록 장벽이 둘 더 든다. 그래서 워프마다의 조건(마지막 질의 조각에서 쉬는 워프)을 없애고 모든 워프가 셈한다 — 쉬는
    워프의 행은 이미 끝 행으로 묶여 있고 쓰기만 막는다(값은 그대로).
- **공유32 의 줄 타일 판**: 판 수 S(미리 올리는 판)를 32 KB 에 드는 만큼 줄인다(블록 차례 그대로). 판 하나가 이미 16 KB 를 넘는 판
  (깊은 · 넓은)은 그대로 빠진다.
- 바뀌는 것은 공유32 모듈(커널생성 --공유32)뿐이다. 보통 모듈 · 0.5B 모듈은 바이트까지 그대로다.

### 판정
- **35a 맞음(판정)** — 다음이 모두 맞아야 시간을 잰다.
  - (1) 보통 모듈 일곱의 소스 · PTX · SPIR-V 가 바이트까지 그대로(빠른 점검).
  - (2) 공유32 협력 모듈(16x16x32 — 이 PC)로 머리128 이 CPU 참조와 다른 칸 0(Vulkan).
  - (3) 공유32 모듈(기본 · 협력)로 다섯 길(Q8_0 · Q4_0)이 23b 기록과 바이트까지 같다 — Vulkan 에서 AMD 의 한도를 흉내 내어.
- **35b 이 PC 의 흉내(기록)**: 자기 진단의 여덟 줄 · 프롬프트 512 · 2048 을 고치기 전과 번갈아.
- **35c AMD(판정 — 친구 PC 의 자기 진단, 협력 모듈)**: 여덟 줄 문맥 2048 의 합이 바닥의 2.5 배 이하(지금 5.45), 프롬프트 2048 의
  어텐션이 600 ms 이하(지금 2,375 ms). R1 생성 시간은 기록이다.

- (2) 머리128: 공유32 협력 모듈(16x16x32)로 다른 칸 0 — 키 · 값을 번갈아 올리는 협력 어텐션이 CPU 참조와 비트까지 같다.
- (3) 다섯 길(Vulkan, AMD 한도 흉내 — 공유 32768 · 푸시 128 · 할당 2 GiB): 공유32 Q8_0 · Q4_0 의 기본 · 협력(16x16x32) 모듈 넷 모두 23b 와
  바이트까지 같다. 판23(줄 타일 판 포함)도 넷 모두 282 경우 0.
- 생성기 `--35없이` 는 34m 의 공유32 모듈과 바이트까지 같은 모듈을 낸다(소스 49c2f683 · ca9902d0, SPIR-V 5142342e · 61457268 —
  speedV 가 같은 때 번갈아 잴 수 있게).
