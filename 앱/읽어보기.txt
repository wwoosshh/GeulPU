GeulPU — 글(geul) 언어로 쓴 LLM 추론 엔진 (Windows x64)

시작
  1. 이 폴더를 아무 곳에나 풉니다(예: C:\GeulPU). 경로에 한글이 있어도 됩니다.
  2. GeulPU.exe 를 두 번 누릅니다. 브라우저에 http://127.0.0.1:44544 가 열립니다.
     - "Windows 의 PC 보호" 창이 뜨면 [추가 정보] → [실행]. (서명하지 않은 실행 파일이라 그렇습니다.)
     - 검은 창(관리자)을 닫으면 GeulPU 가 꺼집니다.
  3. 화면의 [모델] 에서 모델을 받거나(출처 · 크기를 보이고 누른 뒤에 받음), 이미 받은 GGUF 를 더합니다.
  4. [채팅] 에서 모델을 고르고 말을 겁니다. 처음 한 번은 이 GPU 에 맞는 커널을 만들고 판을 재느라 조금 걸립니다.
  5. [벤치 · 검증] 에서 자기 진단 · 속도 · 교차검증(기준 PC 와 비트까지 같은지)을 돌리고, 결과를 zip 으로 받아 보낼 수 있습니다.

필요한 것
  - Windows 10 / 11 (64 비트), 그래픽 드라이버(NVIDIA · AMD · Intel 의 최신).
  - NVIDIA RTX 30 이상은 CUDA 로, 그 밖(AMD 등)은 Vulkan 으로 돕니다. VRAM 8 GB 이상(7B Q8_0 은 12 GB).
  - 인터넷은 모델을 받을 때와 새 판 알림에만 씁니다.

자료
  모델 · 이 GPU 의 커널 · 결과 · 설정은 %USERPROFILE%\GeulPU 에 둡니다(판을 바꿔도 그대로). 바꾸려면 GEULPU_HOME 환경 변수.
  다른 프로그램은 http://127.0.0.1:44544/v1 (OpenAI 꼴 API)로 쓸 수 있습니다 — 이 PC 안에서만 들립니다.

새 판
  화면이 GitHub 의 최신 릴리스를 알려 줍니다. 새 zip 을 다른 폴더에 풀고 그 GeulPU.exe 를 실행하면 됩니다(모델은 다시 받지 않음).
  파일마다의 SHA-256 은 version.json 에, zip 의 SHA-256 은 릴리스의 SHA256SUMS.txt 에 있습니다.

소스 · 문서: https://github.com/wwoosshh/GeulPU

GeulPU — an LLM inference engine written in the geul (글) language.
Unzip anywhere, run GeulPU.exe; the UI opens at http://127.0.0.1:44544 (local only). Download or add GGUF models,
chat, and run self-diagnosis, speed and cross-check benchmarks from the browser. Data lives in %USERPROFILE%\GeulPU.
NVIDIA RTX 30+ runs on CUDA, other GPUs (AMD, ...) on Vulkan. Source: https://github.com/wwoosshh/GeulPU
